# Revision review tools

`prepare_revision_review.py` reads existing conversion outputs and writes a new review directory outside the production output root. It does not rerun conversion, alter preferred origins, edit the manuscript or certify a release.

```sh
python validation/prepare_revision_review.py \
  --output-root /path/to/Pinatubo1991Processing/utc \
  --out /path/to/new-review-directory
```

Outputs:

- `same_source_duplicate_groups.csv`: all groups with repeated source origins, including identical ones.
- `brun_differing_groups.csv`: BRUN groups differing in time, latitude, longitude, depth or magnitude. Missing values are included in the comparison.
- `brun_differing_origins.csv`: the source rows and current preferred-origin flags for human review.
- `counts.json` and `counts.tex`: separately named merged and retained pick counts; suppression-stage counts; waveform, origin, group and container counts. LaTeX command names contain letters only.
- `provenance.json`: hashes of the actual input bytes, comparison fields, distance convention and tool hash.

Pick conservation and group membership are checked before any output is written. The destination must be new. The hashes document a snapshot; they do not prove that every input belongs to one frozen pipeline release. Use the count macros in the manuscript only after release validation.

## Tests

Use an environment with the project's FloVoPy and ObsPy dependencies. Route test artifacts to a temporary results directory:

```sh
PINATUBO_RESULTS_ROOT=/tmp/pinatubo-revision-tests \
PYTHONDONTWRITEBYTECODE=1 \
PYTHONPATH=.:10_conversion:20_analysis \
python -m pytest -q -p no:cacheprovider \
  tests 10_conversion/lib/tests 10_conversion/tests 20_analysis/tests
```

`10_conversion/tests/test_revision_regressions.py` exercises the fixes with synthetic counterexamples and temporary exports. The scientific grouping policy, duplicate-pick policy, clock corrections and measured anchor offsets are unchanged. Grouping sensitivity, representative-origin decisions, local travel-time modelling and manual waveform assessment remain separate validation work.
