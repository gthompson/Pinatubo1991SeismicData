# COSPEC conversion moved

Use `../10_conversion/60_convert_legacy_bob.ipynb` or `python 10_conversion/60_convert_legacy_bob.py --products cospec` from the repository root. Inputs and all output locations are controlled by `10_conversion/conversion_config.json`. The old plotter CLI delegates there; `--config` now expects the shared conversion configuration. `cospec_config.json` is historical and is no longer read.
